---VCP桌面核心---
## 1. 流式自定义 HTML 挂件
VCP桌面是VCP项目的高级进阶功能，允许Agent直接和用户的桌面进行交互。VCP桌面是基于Vchat核心渲染架构搭建的独立桌面系统，其内核是一张空白的html画布，但拥有winsdk和命令行等多重虚拟化，并封装了vchat前端应用群ipc和后端vcp所有api的虚拟化包装，使得几乎完美复刻了pc桌面的所有功能，并可以轻易调用前端和后端的所有关键功能节点和数据节点。
VCP桌面继承了Vchat的强大流式渲染器，可以渲染“任何”内容。

在vchat中，可以直接通过流式输入来“流式生成”widget应用。

直接流式输出注入widget
```
<<<[DESKTOP_PUSH]>>>
<div style="padding:16px; background:rgba(0,0,0,0.5); color:#fff;">
  <h2>标题</h2>
  <p>内容</p>
</div>
<<<[DESKTOP_PUSH_END]>>>
```
该方法可以创建诸如
['<!doctype', '<div', '<section', '<article', '<main', '<header', '<nav', '<aside', '<canvas', '<svg', '<style', 'target:'];
等等功能内容，支持几乎所有js类，尤其是对anime.js和three.js有强大优化。[需要注意推送的开头必须是以上白名单字符，否则会被忽略]

## 2. 利用流式输出编辑widget

<<<[DESKTOP_PUSH]>>>
target:「始」.vw-temp-now「末」,
replace:「始」<span style="font-size:52px;">22°C</span>「末」
<<<[DESKTOP_PUSH_END]>>>

创建的widget直接运行在内存中，当用户选择收藏widget对应挂件会被持久化储存。
被收藏的widget储存于.\VCPChat\AppData\DesktopWidgets目录，被储存的Widget允许调用同目录下的内部外挂js文件，且支持访问vchat应用群所有依赖，ipc。支持createRange、createComment、createDocumentFragment、addEventListener、removeEventListener、documentElement 等方法。

## 3. JS 沙箱与 Shadow DOM 开发限制
*   **局部封闭**：DOM 增删改查、样式和事件绑定必须限制在主容器内（如 `<div id="app">`）。禁用 `document.body`、`document.head`，禁止全局 `window` 事件监听（因事件重定向无法获取真实 target），CSS 禁用 `body`/`html` 选择器且不适用全局 Tailwind。
*   **同步经典脚本**：JS 以 IIFE 闭包同步运行。禁用 ES Module (`import`/`export`)，禁用全局顶层 `await`（异步操作必须包裹在 `async` 函数内或使用 `.then()` 链）。
*   **专属通道**：禁用 `document.currentScript`。必须使用注入的 API（`vcpAPI`、`musicAPI`、`window.nfm`）。自定义右键菜单需 `preventDefault()` 阻止系统桌面菜单。

## 4. 本地文件挂载挂件 (CreateNativeFileMount)
**创建指令格式**（通过 `DesktopRemote` 工具执行）：
command: CreateNativeFileMount
mountPath:「始」D:\Projects「末」
mode: [readonly|readwrite] (默认 readonly)
width: 400
height: 650

*   **外壳坐标与尺寸 **：`width`, `height`, `x`, `y`
*   **外壳样式定制 (`frame_*`)**：`transparent` (透明), `showGrip` (手柄), `showCloseButton` (关闭键), `resizable` (缩放), `background`, `border`, `shadow`, `opacity`。
    *   特别地，设置 `frame_minimal: true` 会一键清零外壳样式（无边框、无手柄、无关闭按钮，其余 `frame_*` 细项不生效），适用于 customUI 自绘界面。
*   **内容区定制 (`ui_*`)**：
    *   `theme_*`：自定义 `primary`, `background`, `foreground`, `border`, `hover`, `accent` 色彩。
    *   `layout_variant`：可选 `"grid"` 或 `"list"`。
    *   `icons.[ext]`：后缀图标映射。
    *   `actions_toolbar` / `actions_contextMenu`：逗号分隔过滤可用按钮（可选：`up`, `path`, `refresh`, `newfolder`, `newfile`, `delete`, `paste`, `open`, `reveal`, `rename`, `copy`, `cut`, `unzip`）。
*   **CustomUI 完全接管模式**：配置以下项将跳过 theme/layout/actions 等默认渲染：
    ui_customUI_html:「始」<div id="app">界面</div>「末」
    ui_customUI_css:「始」#app { color: #fff; }「末」
    ui_customUI_js:「始ESCAPE」
    // 必须挂载在局部容器上。调用 window.nfm API（包含: list, open, reveal, newFolder, newFile, rename, trash, copyToClipboard, cutToClipboard, paste, unzip, onFileChange）。
    // list返回Promise，文件条目需由result.entries数组获取：nfm.list(".").then(r => console.log(r.entries));
    // 解压：nfm.unzip("archive.zip", "destDir")
    「末ESCAPE」

## 5. 文件挂件配置动态编辑 (EditNativeFileMount)
通过局部文本替换更新已有挂件配置（无需重建）：
command: EditNativeFileMount
widgetId: [挂件ID]   //不确定时可通过`QueryDesktop`命令查询
target: mountPath:「始」D:\OldPath「末」
replace: mountPath:「始」D:\NewPath「末」

## 6. 桌面状态感知与调试（DesktopRemote Tool 命令集）
*   `QueryDesktop`：查询活跃挂件（ID、类型、路径）。NativeFileMount 类型会额外返回 `mountPath`, `mode`, `currentPath`, `selectedItems`, `status`, `errorMessage`。
*   `ViewWidgetSource`：获取指定挂件 ID 的完整 HTML 源码或配置文本。
*   `CreateNativeFileMount`：创建文件挂载挂件（见第4节）。
*   `EditNativeFileMount`：修改文件挂件配置（见第5节）。
*   `CreateWidget`：通过工具创建 HTML 挂件（等效于 DESKTOP_PUSH，但有执行反馈）。
*   `SetStyleAutomation` / `GetStyleAutomationStatus`：设置/获取样式自动化配置。
