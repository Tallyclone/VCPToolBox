# VCP 多媒体工具箱能力收纳
这里收纳了各种强大的多媒体生成与控制工具。

[===vcp_fold:0.3===]

## 1. 统一生图/修图/多图合成
以下生图工具已做字段兼容，AI无需记多套命令。所有模型的prompt均支持纯自然语言描述，中文或英文都可以；需要文字排版、字体特效、画面风格、人物动作、镜头语言时直接在prompt中详细描述即可。

### 推荐优先使用
- ZImageTurboGen：国产开源图像模型，支持文本生成、修图、多图合成，NSFW相对宽松。每日有100点免费算力额度。
- DMXDoubaoGen：国产强图像模型，字体/中文排版/海报类任务表现强，输出规格偏高。
- NanoBananaGen2：顶级图像编辑AI，适合长描述、复杂修图、多图参考和角色一致性任务。
- GPTImageGen：OpenAI超大参数图片编辑模型，适合通用生成与编辑。

### 统一调用格式
tool_name:「始」ZImageTurboGen 或 DMXDoubaoGen 或 NanoBananaGen2 或 GPTImageGen「末」,
command:「始」generate / edit / compose「末」,
prompt:「始」(必需) 用于生成、编辑或合成图片的自然语言描述，支持中文或英文。纯文本描述即可，不需要特殊格式。「末」,
size:「始」(可选) 统一尺寸字段，也兼容resolution和image_size。可写1024x1024、1536x1024、2K、4K、adaptive等，具体可用值取决于所选模型。「末」,
image:「始」(编辑/合成时必需) 单图URL/base64/data URI，或图片数组，例如["url1","url2"]。也兼容image_url、image_1、image_2、image_url_1、image_base64_1等字段。「末」,
negative_prompt:「始」(可选) 不希望出现的内容，例如模糊、低质量、变形、错误文字等。只有Zimage支持该功能。「末」,
showbase64:「始」(可选) 是否在返回结果中附带 base64 图片数据供直接查看，默认 false。可填 true 或 false。「末」

### 使用规则
- image可以直接写数组：image:「始」["url1","url2"]「末」
- image也可以写编号字段分开传url：image_1、image_2。

### 模型差异注意
- ZImageTurboGen：文生图会自动贴近固定支持分辨率；输入比例/尺寸会被映射到最接近的可用规格。编辑/合成走异步任务，输入图片会先转base64再提交。
- DMXDoubaoGen：不适合生成低于2K的图片，建议size写2K、4K、2048x2048或adaptive。
- NanoBananaGen2：image_size主要支持1K、2K、4K；长prompt和复杂修图适合优先使用。
- GPTImageGen：支持具体宽高如1024x1024、1536x1024；4K属于实验性/不稳定能力，失败时降低尺寸重试。

## 2. 外部音乐播放器 (MusicPlay)
用于控制 VCP Music Player 的播放、下载、切歌、音量及歌单管理。

### 基础控制与状态
tool_name:「始」MusicPlay「末」,
command:「始」controlPlayer「末」,
action:「始」open/close/quit/minimize/show/play/pause/next/prev/volume/playMode「末」, // minimize(最小化到托盘), show(从托盘唤起恢复窗口)
value:「始」value「末」// volume 传 0~1 (如0.5)；playMode 可选 'repeat'/'repeat-one'/'shuffle'

获取播放状态（当前曲目、进度及模式）：
command:「始」getPlayerState「末」

### 在线检索与点播
在线检索：
command:「始」searchOnline「末」,
query:「始」周杰伦「末」,
platform:「始」all/netease/qq/kuwo「末」

本地曲库列表：
command:「始」getLibrary「末」

随便听听：
command:「始」randomListen「末」,
platform:「始」netease/qq/kuwo「末」,
tag:「始」hot/new/soaring「末」 // 对应热歌/新歌/飙升，或分类标签如'华语'

### 点播、追加与下载
点播单/多曲：
command:「始」playTrack「末」,
tracks:「始」netease|60264|不要说我们是朋友|阿木;netease|60263|他一定很爱你|阿杜「末」, // DSL格式：平台|ID|歌名|歌手，多首用分号分隔。本地为：local|路径|歌名|歌手
quality:「始」flac/320k/128k「末」

追加稍后播放：
command:「始」addTracksToQueue「末」,
tracks:「始」netease|60264|不要说我们是朋友|阿木「末」,
quality:「始」flac/320k/128k「末」

批量下载（优先离线秒拷本地 Temp 缓存并重扫曲库）：
command:「始」downloadTrack「末」,
tracks:「始」netease|60264|不要说我们是朋友|阿木「末」,
quality:「始」flac/320k/128k「末」

### 自定义歌单管理
command:「始」manageCustomPlaylist「末」,
action:「始」query/create/delete/play/playSong/addSong/removeSong「末」, // query(查全部), create(建歌单), delete(删歌单), play(播整单)
id:「始」歌单id「末」, // delete/play/playSong/addSong/removeSong 时必需
name:「始」歌单名称「末」, // create 必需
tracks:「始」netease|60264|不要说我们是朋友|阿木「末」, // addSong/removeSong 批量加/删歌曲，支持分号分隔
songIndex:「始」0;2「末」, // playSong/removeSong 可选，支持分号分隔索引
songTitle:「始」晴天;告白气球「末」, // playSong/removeSong 可选，支持分号分隔歌名匹配
trackPath:「始」path1;path2「末」 // removeSong 可选，支持分号分隔物理路径匹配

## 4. Grok 视频生成 (GrokVideoGen)
马斯克出品，极速生成 6 秒视频，包含高质量配音，支持 NSFW。
tool_name:「始」GrokVideoGen「末」,
image_url:「始」(必需) 底图链接「末」,
prompt:「始」(必需) 描述视频内容和配音「末」,
video_url:「始」(可选) 用于视频续写「末」

### 视频拼接
command:「始」concat「末」,
video_url1:「始」[第一个URL]「末」,
video_url2:「始」[第二个URL]「末」
